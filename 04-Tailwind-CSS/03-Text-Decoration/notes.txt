📌 What is Text Decoration?

Text Decoration is used to add or remove decorative lines from text.

Tailwind CSS provides utility classes for applying text decorations without writing custom CSS.

-----------------------------------------
1. underline
-----------------------------------------

Definition:
Adds a line below the text.

Syntax:
class="underline"

Example:
<p class="underline">Hello Tailwind CSS</p>

Output:
The text is displayed with an underline.

-----------------------------------------
2. overline
-----------------------------------------

Definition:
Adds a line above the text.

Syntax:
class="overline"

Example:
<p class="overline">Hello Tailwind CSS</p>

Output:
The text is displayed with an overline.

-----------------------------------------
3. line-through
-----------------------------------------

Definition:
Adds a line through the middle of the text.

Syntax:
class="line-through"

Example:
<p class="line-through">Hello Tailwind CSS</p>

Output:
The text appears crossed out.

-----------------------------------------
4. no-underline
-----------------------------------------

Definition:
Removes underline from text or links.

Syntax:
class="no-underline"

Example:
<a href="#" class="no-underline">Home</a>

Output:
The link appears without an underline.

-----------------------------------------
Why Use Text Decoration?
-----------------------------------------

✔ Highlight important text
✔ Remove link underline
✔ Show deleted or completed items
✔ Improve UI design
✔ No custom CSS required

-----------------------------------------
Advantages
-----------------------------------------

• Easy to use
• Utility-first classes
• Responsive friendly
• Faster development
• Clean and readable code
