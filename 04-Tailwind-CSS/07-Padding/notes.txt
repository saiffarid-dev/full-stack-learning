Tailwind CSS - Topic 07 : Padding
=========================================

📌 What is Padding?

Padding is the space inside an element.
It creates space between the content and the border.

-----------------------------------------
Syntax
-----------------------------------------

class="p-4"

Example:

<div class="p-4">
    Hello Tailwind CSS
</div>

-----------------------------------------
Padding Types
-----------------------------------------

p-4
→ Padding on all sides

pt-4
→ Padding Top

pb-4
→ Padding Bottom

pl-4
→ Padding Left

pr-4
→ Padding Right

px-4
→ Padding Left & Right

py-4
→ Padding Top & Bottom

-----------------------------------------
Common Values
-----------------------------------------

p-1
p-2
p-3
p-4
p-5
p-6
p-8
p-10

-----------------------------------------
Example
-----------------------------------------

<h1 class="bg-red-500 text-white p-4">
    Padding All Sides
</h1>

<h1 class="bg-blue-500 text-white pt-4">
    Padding Top
</h1>

<h1 class="bg-green-500 text-white px-4">
    Padding Left & Right
</h1>

<h1 class="bg-purple-500 text-white py-4">
    Padding Top & Bottom
</h1>

-----------------------------------------

-----------------------------------------

✔ Easy Spacing
