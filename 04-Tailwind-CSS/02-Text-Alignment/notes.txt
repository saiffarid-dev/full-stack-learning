📌 What is Text Alignment?

Text Alignment is used to control the horizontal position of text inside an element.

Tailwind CSS provides predefined utility classes for aligning text.

-------------------------------------------
1. text-left
-------------------------------------------

Definition:
Aligns text to the left side.

Syntax:
class="text-left"

Example:
<p class="text-left">Hello Tailwind CSS</p>

Output:
Text appears on the left side.

-------------------------------------------
2. text-center
-------------------------------------------

Definition:
Aligns text to the center.

Syntax:
class="text-center"

Example:
<p class="text-center">Hello Tailwind CSS</p>

Output:
Text appears in the center.

-------------------------------------------
3. text-right
-------------------------------------------

Definition:
Aligns text to the right side.

Syntax:
class="text-right"

Example:
<p class="text-right">Hello Tailwind CSS</p>

Output:
Text appears on the right side.

-------------------------------------------
4. text-justify
-------------------------------------------

Definition:
Aligns text evenly on both the left and right sides.

Syntax:
class="text-justify"

Example:
<p class="text-justify">
Tailwind CSS is a utility-first CSS framework.
</p>

Output:
Text is aligned evenly on both sides.
