# Tailwind CSS - Flexbox

## Introduction
Flexbox is a one-dimensional layout system used to arrange elements in rows or columns. It helps create responsive and well-aligned layouts.

------------------------------------------------

1. Flex
Class:
flex

Purpose:
Makes an element a flex container.

Example:
<div class="flex"></div>

------------------------------------------------

2. Flex Direction

Classes:
flex-row
flex-col

Purpose:
Controls the direction of flex items.

Example:
<div class="flex flex-row"></div>
<div class="flex flex-col"></div>

------------------------------------------------

3. Justify Content

Classes:
justify-start
justify-center
justify-end
justify-between
justify-around
justify-evenly

Purpose:
Aligns items horizontally along the main axis.

Example:
<div class="flex justify-between"></div>

------------------------------------------------

4. Align Items

Classes:
items-start
items-center
items-end
items-stretch

Purpose:
Aligns items vertically on the cross axis.

Example:
<div class="flex items-center"></div>

------------------------------------------------

5. Gap

Classes:
gap-2
gap-4
gap-6
gap-8

Purpose:
Adds spacing between flex items.

Example:
<div class="flex gap-4"></div>

## Interview Questions

Q1. What is Flexbox?
Ans: A one-dimensional layout system for arranging items in rows or columns.

Q2. What does `flex` do?
Ans: Converts an element into a flex container.

Q3. Difference between `justify-content` and `align-items`?
Ans:
- justify-content → Horizontal alignment (main axis)
- align-items → Vertical alignment (cross axis)

Q4. What is `gap`?
Ans: Adds spacing between flex items without using margin.

------------------------------------------------

## Summary

✔ flex → Enable Flexbox
✔ flex-row → Horizontal layout
✔ flex-col → Vertical layout
✔ justify-* → Horizontal alignment
✔ items-* → Vertical alignment
✔ gap-* → Space between items
