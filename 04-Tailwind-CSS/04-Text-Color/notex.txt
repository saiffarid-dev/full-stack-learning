📌 What is Text Color?

Text Color is used to change the color of text.

Tailwind CSS provides predefined utility classes to apply colors without writing custom CSS.

-----------------------------------------
Syntax
-----------------------------------------

class="text-{color}-{shade}"

Example:

text-red-500

-----------------------------------------
Common Text Colors
-----------------------------------------

text-black      → Black

text-white      → White

text-red-500    → Red

text-blue-500   → Blue

text-green-500  → Green

text-yellow-500 → Yellow

text-purple-500 → Purple

text-pink-500   → Pink

text-gray-500   → Gray

-----------------------------------------
