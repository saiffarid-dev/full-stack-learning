=========================================
What is Bootstrap?
=========================================

Bootstrap is a free and open-source Front-End CSS Framework.

It helps developers build responsive and mobile-first websites quickly using pre-built CSS classes and JavaScript components.

-----------------------------------------
Why Bootstrap?
-----------------------------------------

- Faster Development
- Responsive Design
- Mobile First
- Ready-made Components
- Utility Classes
- Cross Browser Support
- Free & Open Source

-----------------------------------------
Bootstrap History
-----------------------------------------

- Developed by Mark Otto and Jacob Thornton.
- Created at Twitter in 2010.
- Released as Open Source in 2011.
- Originally known as Twitter Blueprint.

-----------------------------------------
Bootstrap Installation Methods
-----------------------------------------

1. CDN (Recommended for Beginners)
2. Download Bootstrap Files
3. npm install bootstrap (Professional Method)

-----------------------------------------
CDN
-----------------------------------------

CDN = Content Delivery Network

CDN allows us to use Bootstrap without downloading or installing any files.

-----------------------------------------
How Bootstrap Works?
-----------------------------------------

1. Browser loads Bootstrap CSS.
2. Bootstrap CSS already contains predefined classes.
3. We use those classes in HTML.
4. Browser automatically applies the design.

-----------------------------------------
Where are Bootstrap Classes?
-----------------------------------------

Bootstrap classes are already written inside bootstrap.min.css.

We normally view and learn them from the official Bootstrap Documentation.
