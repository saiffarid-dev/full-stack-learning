# Bootstrap Topic 22
# Pagination

=========================================
What is Bootstrap Pagination?
=========================================

Bootstrap Pagination is used to navigate between multiple pages of content.

=========================================
Why Use Pagination?
=========================================

- Easy Navigation
- Responsive Design
- Better User Experience
- Professional UI
- Less Custom CSS

=========================================
Important Classes
=========================================

pagination
→ Main pagination container.

page-item
→ Creates each page.

page-link
→ Creates clickable page links.

active
→ Highlights the current page.

disabled
→ Disables a page button.

pagination-lg
→ Large pagination.

pagination-sm
→ Small pagination.

=========================================
Basic Syntax
=========================================

<ul class="pagination">

<li class="page-item">
<a class="page-link" href="#">1</a>
</li>

</ul>

=========================================
Pagination Sizes
