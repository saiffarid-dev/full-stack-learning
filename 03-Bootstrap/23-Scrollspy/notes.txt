# Bootstrap Topic 23
# Scrollspy

=========================================
What is Bootstrap Scrollspy?
=========================================

Bootstrap Scrollspy automatically updates the active navigation link while the user scrolls through the page.

=========================================
Why Use Scrollspy?
=========================================

- One Page Website
- Portfolio Website
- Landing Page
- Better Navigation
- Better User Experience

=========================================
Important Attributes
=========================================

data-bs-spy="scroll"
→ Enables Scrollspy.

data-bs-target="#navbar"
→ Connects Scrollspy with the navbar.

tabindex="0"
→ Makes the scroll area focusable.

=========================================
Important Classes
=========================================

navbar
→ Navigation bar.

nav
→ Navigation container.

nav-item
→ Navigation item.

nav-link
→ Navigation link.

active
→ Highlights the active link.

sticky-top
→ Keeps navbar fixed at the top while scrolling.

=========================================
Basic Syntax
=========================================

<body
data-bs-spy="scroll"
data-bs-target="#navbar"
tabindex="0">

<nav id="navbar">
...
</nav>

</body>

=========================================
Common Mistakes
=========================================

❌ data-bs-spy="scrol"
✅ data-bs-spy="scroll"

❌ data-bs-target="navbar"
✅ data-bs-target="#navbar"

❌ Forgetting tabindex="0"

❌ Section id and nav href do not match.
