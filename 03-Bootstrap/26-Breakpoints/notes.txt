# Bootstrap Topic 27
# Responsive Breakpoints

=========================================
What are Bootstrap Breakpoints?
=========================================

Bootstrap Breakpoints are predefined screen sizes used to create responsive websites.

=========================================
Why Use Breakpoints?
=========================================

- Responsive Design
- Mobile Friendly
- Tablet Support
- Desktop Layout
- Better User Experience

=========================================
Bootstrap Breakpoints
=========================================

xs  → <576px

sm  → ≥576px

md  → ≥768px

lg  → ≥992px

xl  → ≥1200px

xxl → ≥1400px

=========================================
Important Classes
=========================================

col-12
→ Full width on all devices.

col-sm-6
→ 2 columns on small devices.

col-md-6
→ 2 columns on tablets.

col-lg-4
→ 3 columns on large screens.

col-xl-3
→ 4 columns on extra large screens.

row
→ Creates a row.

container
→ Main responsive container.

g-3
→ Adds gap between columns.

=========================================
Common Mistakes
=========================================

❌ col-md4
✅ col-md-4

❌ col-lg6
✅ col-lg-6

❌ Missing row class
✅ Always wrap columns inside a row.

❌ Missing container
✅ Use container or container-fluid.
