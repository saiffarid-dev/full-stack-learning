# Bootstrap Topic 25
# Bootstrap Icons

=========================================
What are Bootstrap Icons?
=========================================

Bootstrap Icons are a free icon library used with Bootstrap to add beautiful and professional icons to websites.

=========================================
Why Use Bootstrap Icons?
=========================================

- Easy to Use
- Professional UI
- Responsive
- Lightweight
- Free
- Modern Design

=========================================
Installation
=========================================

Include Bootstrap Icons CDN.

<link rel="stylesheet"
href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">

=========================================
Basic Syntax
=========================================

<i class="bi bi-house-fill"></i>

=========================================

=========================================

=========================================
Useful Bootstrap Classes
=========================================

bi
→ Base icon class

text-primary
→ Blue icon

text-success
→ Green icon

text-danger
→ Red icon

fs-1
→ Large icon size

fs-3
→ Medium icon size
