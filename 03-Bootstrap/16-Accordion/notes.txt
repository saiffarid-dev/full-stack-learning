# Bootstrap Topic 16
# Accordion

=========================================
What is Bootstrap Accordion?
=========================================

Bootstrap Accordion is a component used to show and hide content by clicking on a header.

=========================================
Why Use Bootstrap Accordion?
=========================================

- Professional UI
- Saves Screen Space
- Responsive Design
- Easy Navigation
- Less Custom CSS
- User Friendly

=========================================
Important Accordion Classes
=========================================

accordion
→ Main accordion container.

accordion-item
→ Creates an accordion section.

accordion-header
→ Creates the heading.

accordion-button
→ Clickable button to open/close content.

accordion-collapse
→ Contains the collapsible content.

accordion-body
→ Stores the content inside the accordion.

collapse
→ Hides the content by default.

show
→ Displays the content by default.

=========================================
Basic Accordion
=========================================

<div class="accordion">

Creates the main accordion container.

-----------------------------------------

<div class="accordion-item">

Creates one accordion item.

-----------------------------------------

<h2 class="accordion-header">

Creates the accordion heading.

-----------------------------------------

<button class="accordion-button">

Creates the clickable button.

-----------------------------------------

<div class="accordion-collapse collapse">

Creates the collapsible section.

-----------------------------------------

<div class="accordion-body">

Stores the accordion content.

Common Mistakes
=========================================

❌ accordian
✅ accordion

❌ accordion-items
✅ accordion-item

❌ accordion-btn
✅ accordion-button

❌ accordion-collapsee
✅ accordion-collapse

❌ data-bs-target="#item"
(id missing)

✅ data-bs-target="#item1"

and

id="item1"

Both must match.
