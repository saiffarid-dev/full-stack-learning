# Bootstrap Topic 02
# Buttons

=========================================
What is a Bootstrap Button?
=========================================

Bootstrap Button is a pre-designed clickable element.

Bootstrap provides ready-made button styles using classes.

Syntax

<button class="btn btn-primary">
    Click Me
</button>

=========================================
Required Class
=========================================

btn

The "btn" class is mandatory.

Without btn class Bootstrap button styling will not work.

Example

<button class="btn">
Button
</button>

Button Sizes
=========================================

Example

</button>

</button>

Full Width Button
=========================================

Example

</button>
