# Bootstrap Topic 14
# Progress Bars

=========================================
What are Bootstrap Progress Bars?
=========================================

Bootstrap Progress Bars are used to display the progress of a task, upload, download, loading process, or completion percentage.

=========================================
Why Use Bootstrap Progress Bars?
=========================================

- Show Task Progress
- Professional UI
- Responsive Design
- Easy to Customize
- Better User Experience
- Less Custom CSS

=========================================
Important Progress Classes
=========================================

progress
→ Main progress container.

progress-bar
→ Displays the progress.

bg-success
→ Green progress bar.

bg-danger
→ Red progress bar.

bg-warning
→ Yellow progress bar.

bg-primary
→ Blue progress bar.

progress-bar-striped
→ Adds striped effect.

progress-bar-animated
→ Adds animation.

=========================================
Basic Progress Bar
=========================================

<div class="progress">
    <div class="progress-bar" style="width:50%">
        50%
    </div>
</div>

Creates a simple progress bar.

=========================================
Striped Progress Bar
=========================================

<div class="progress-bar progress-bar-striped">

Creates a striped progress bar.

=========================================
Animated Progress Bar
=========================================

<div class="progress-bar progress-bar-striped progress-bar-animated">

Creates an animated progress bar.

=========================================
Colored Progress Bars
=========================================

bg-success → Green

bg-danger → Red

bg-warning → Yellow

bg-primary → Blue
