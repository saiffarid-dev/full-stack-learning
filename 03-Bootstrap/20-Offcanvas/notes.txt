# Bootstrap Topic 20
# Offcanvas

=========================================
What is Bootstrap Offcanvas?
=========================================

Bootstrap Offcanvas is a sidebar component that slides into the screen from the left, right, top, or bottom.

=========================================
Why Use Bootstrap Offcanvas?
=========================================

- Responsive Sidebar
- Mobile Navigation
- Shopping Cart
- Filter Panel
- User Menu
- Less Custom CSS

=========================================
Important Offcanvas Classes
=========================================

offcanvas
→ Main offcanvas container.

offcanvas-start
→ Opens from the left.

offcanvas-end
→ Opens from the right.

offcanvas-top
→ Opens from the top.

offcanvas-bottom
→ Opens from the bottom.

offcanvas-header
→ Header section.

offcanvas-title
→ Sidebar title.

offcanvas-body
→ Main content section.

btn-close
→ Close button.

=========================================
Important Data Attributes
=========================================

data-bs-toggle="offcanvas"
→ Opens the Offcanvas.

data-bs-target="#menu"
→ Targets the Offcanvas ID.

data-bs-dismiss="offcanvas"
→ Closes the Offcanvas.

=========================================
Basic Structure
=========================================

<div class="offcanvas offcanvas-start">

<div class="offcanvas-header">

<h5 class="offcanvas-title">

<div class="offcanvas-body">

Creates a complete Bootstrap Offcanvas.

=========================================
Common Mistakes
=========================================

❌ offcanva
✅ offcanvas

❌ offcanvas-head
✅ offcanvas-header

❌ offcanvas-content
✅ offcanvas-body

❌ data-bs-toggle="canvas"
✅ data-bs-toggle="offcanvas"

❌ data-bs-dismiss="canvas"
✅ data-bs-dismiss="offcanvas"

❌ Wrong ID in data-bs-target

✅ data-bs-target="#menu"

and

id="menu"

Both must match.
