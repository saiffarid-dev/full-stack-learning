# Bootstrap Topic 15
# List Group

=========================================
What is Bootstrap List Group?
=========================================

Bootstrap List Group is a component used to display a collection of items in a clean, professional, and responsive list.

=========================================
Why Use Bootstrap List Group?
=========================================

- Professional UI
- Responsive Design
- Easy Navigation
- Easy to Customize
- Less Custom CSS

=========================================
Important List Group Classes
=========================================

list-group
→ Main list container.

list-group-item
→ Creates each list item.

active
→ Highlights the selected item.

disabled
→ Disables a list item.

list-group-numbered
→ Creates a numbered list.

list-group-flush
→ Removes the outer borders.

=========================================
Basic List Group
=========================================

<ul class="list-group">
    <li class="list-group-item">HTML</li>
</ul>

Creates a basic Bootstrap list.

=========================================
Active Item
=========================================

<li class="list-group-item active">

Highlights the active item.

=========================================
Disabled Item
=========================================

<li class="list-group-item disabled">

Displays a disabled item.

=========================================
Numbered List
=========================================

<ol class="list-group list-group-numbered">

Creates a numbered list.

=========================================
Flush List
=========================================

<ul class="list-group list-group-flush">

Removes the outer border of the list.
