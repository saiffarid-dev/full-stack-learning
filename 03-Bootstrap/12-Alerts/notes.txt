# Bootstrap Topic 12
# Alerts

=========================================
What are Bootstrap Alerts?
=========================================

Bootstrap Alerts are ready-made components used to display important messages, notifications, warnings, errors, and success messages.

=========================================
Why Use Bootstrap Alerts?
=========================================

- Professional Notifications
- Responsive Design
- Easy to Use
- Better User Experience
- Less Custom CSS

=========================================
Important Alert Classes
=========================================

alert
→ Main alert container.

alert-primary
→ Blue information alert.

alert-secondary
→ Gray alert.

alert-success
→ Success message.

alert-danger
→ Error or danger message.

alert-warning
→ Warning message.

alert-info
→ Information message.

alert-light
→ Light-colored alert.

alert-dark
→ Dark-colored alert.

alert-dismissible
→ Allows the user to close the alert.

btn-close
→ Close button for alert.

fade
→ Adds fade animation.

show
→ Displays the alert.

=========================================
Basic Alert
=========================================

<div class="alert alert-primary">

Creates a basic Bootstrap alert.

=========================================
Success Alert
=========================================

<div class="alert alert-success">

Shows a success message.

=========================================
Danger Alert
=========================================

<div class="alert alert-danger">

Shows an error message.

=========================================
Warning Alert
=========================================

<div class="alert alert-warning">

Shows a warning message.

=========================================
Dismissible Alert
=========================================

<div class="alert alert-success alert-dismissible fade show">

Allows the user to close the alert.

=========================================
Close Button
=========================================

<button class="btn-close"
data-bs-dismiss="alert"></button>

Closes the alert.
