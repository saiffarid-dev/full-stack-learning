# Bootstrap Topic 06
# Colors

=========================================
What are Bootstrap Colors?
=========================================

Bootstrap provides predefined color classes to style text, backgrounds, buttons, borders, and other elements without writing custom CSS.

=========================================
Why Use Bootstrap Colors?
=========================================

- Professional UI
- Fast Development
- Consistent Design
- Easy to Use
- No Extra CSS Required

=========================================

=========================================

→ Gray Text

→ Red Text

text-dark

→ Light Gray Text

=========================================
When to Use?
=========================================

text-primary
→ Headings

text-success
→ Success Messages

text-danger
→ Error Messages

bg-primary
→ Cards / Sections

bg-dark
→ Footer / Navbar

btn-success
→ Save Button

btn-danger
→ Delete Button

border-primary
→ Highlight Boxes
