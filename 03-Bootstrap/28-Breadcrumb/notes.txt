# Bootstrap Topic 28
# Breadcrumb

=========================================
What is Bootstrap Breadcrumb?
=========================================

Bootstrap Breadcrumb is a navigation component that shows the user's current location on a website.

Example:

Home > Products > Shoes

=========================================
Why Use Breadcrumb?
=========================================

- Easy Navigation
- Better User Experience
- Professional UI
- Shows Current Page
- Responsive Design

=========================================
Important Classes
=========================================

breadcrumb
→ Main breadcrumb container.

breadcrumb-item
→ Creates each breadcrumb item.

active
→ Highlights the current page.

=========================================
Basic Syntax
=========================================

<nav>

<ol class="breadcrumb">

<li class="breadcrumb-item">
<a href="#">Home</a>
</li>

<li class="breadcrumb-item active">
Products
</li>

</ol>

</nav>

Common Mistakes
=========================================

❌ bread-crumb
✅ breadcrumb

❌ breadcrumb-items
✅ breadcrumb-item

❌ Missing active class

✅ Add active to the current page.
