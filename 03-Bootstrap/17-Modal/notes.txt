# Bootstrap Topic 17
# Modal

=========================================
What is Bootstrap Modal?
=========================================

Bootstrap Modal is a popup dialog box that appears on top of a webpage.

=========================================
Why Use Bootstrap Modal?
=========================================

- Professional UI
- Responsive Design
- Login & Signup Forms
- Confirmation Dialog
- User Notifications
- Less Custom CSS

=========================================
Important Modal Classes
=========================================

modal
→ Main modal container.

modal-dialog
→ Controls modal size and position.

modal-content
→ Main modal box.

modal-header
→ Modal heading section.

modal-title
→ Displays modal title.

modal-body
→ Main modal content.

modal-footer
→ Footer section for buttons.

btn-close
→ Close button.

fade
→ Adds opening/closing animation.

=========================================
Important Data Attributes
=========================================

data-bs-toggle="modal"
→ Opens the modal.

data-bs-target="#myModal"
→ Selects the modal by ID.

data-bs-dismiss="modal"
→ Closes the modal.

=========================================
Basic Modal Structure
=========================================

<div class="modal">
<div class="modal-dialog">
<div class="modal-content">
<div class="modal-header">
<div class="modal-body">
<div class="modal-footer">

Creates a complete Bootstrap Modal.

=========================================
Common Mistakes
=========================================

❌ model
✅ modal

❌ data-bs-toggle="model"
✅ data-bs-toggle="modal"

❌ btnclose
✅ btn-close

❌ modal-dialogue
✅ modal-dialog

❌ data-bs-target="#modal"

When modal ID is:

id="myModal"

Then target must be:

data-bs-target="#myModal"
