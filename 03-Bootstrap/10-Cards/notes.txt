# Bootstrap Topic 10
# Cards

=========================================
What are Bootstrap Cards?
=========================================

Bootstrap Cards are flexible containers used to display images, text, buttons, and other content in a professional layout.

=========================================
Why Use Bootstrap Cards?
=========================================

- Professional UI
- Responsive Design
- Easy to Customize
- Reusable Component
- Less Custom CSS

=========================================
Important Card Classes
=========================================

card
→ Main card container.

card-img-top
→ Displays an image at the top of the card.

card-body
→ Holds the card content.

card-title
→ Displays the card heading.

card-text
→ Displays the description.

btn
→ Creates a Bootstrap button.

btn-primary
→ Creates a blue button.

shadow
→ Adds a shadow effect.

rounded
→ Adds rounded corners.

=========================================
Basic Card
=========================================

<div class="card">

Creates a Bootstrap card.

=========================================
Card Image
=========================================

<img class="card-img-top">

Adds an image at the top of the card.

=========================================
Card Body
=========================================

<div class="card-body">

Contains the card content.

=========================================
Card Title
=========================================

<h5 class="card-title">

Displays the card heading.

=========================================
Card Text
=========================================

<p class="card-text">

Displays the card description.

=========================================
Card Button
=========================================

<button class="btn btn-primary">

Creates a Bootstrap button inside the card.

=========================================
