# Bootstrap Topic 19
# Toast

=========================================
What is Bootstrap Toast?
=========================================

Bootstrap Toast is a lightweight notification popup used to display short messages to users.

=========================================
Why Use Bootstrap Toast?
=========================================

- Professional Notifications
- Responsive Design
- Easy to Use
- Better User Experience
- Less Custom CSS

=========================================
Important Toast Classes
=========================================

toast
→ Main toast container.

toast-header
→ Toast heading section.

toast-body
→ Toast message section.

show
→ Displays the toast.

hide
→ Hides the toast.

btn-close
→ Close button.

me-auto
→ Pushes the close button to the right.

=========================================
Important JavaScript
=========================================

new bootstrap.Toast(element)
→ Creates a Toast object.

toast.show()
→ Shows the toast.
