# Bootstrap Topic 03
# Containers

=========================================
What is a Container?
=========================================

A Bootstrap Container is a responsive wrapper used to align and manage website content.

Container keeps the content properly aligned and responsive on different screen sizes.

=========================================
Why use Container?
=========================================

- Proper Alignment
- Responsive Layout
- Better Spacing
- Professional Design
- Easy Content Management

=========================================
Types of Containers
=========================================

1. container

Responsive Fixed Width Container.

Used for:
- Main Website Content
- Forms
- Cards
- Sections

Example

<div class="container">
    Content
</div>

-----------------------------------------

2. container-fluid

100% Width Container.

Used for:
- Header
- Footer
- Banner
- Hero Section

Example

<div class="container-fluid">
    Content
</div>

-----------------------------------------

3. Responsive Containers

container-sm

container-md

container-lg

container-xl

container-xxl

These containers change width according to screen size.

Important Utility Classes
=========================================

container
→ Fixed Responsive Width

container-fluid
→ Full Width

mt-5
→ Margin Top

p-4
→ Padding

bg-light
→ Light Background

bg-dark
→ Dark Background

text-primary
→ Blue Text

→ White Text

text-center
→ Center Alignment

shadow
→ Shadow Effect

rounded
→ Rounded Corners

btn
→ Bootstrap Button Base Class

btn-success
→ Green Button

btn-danger
→ Red Button

btn-outline-primary
→ Blue Border Button

me-2
→ Right Margin Between Elements

When to Use?
=========================================

container
→ Normal Website Layout

container-fluid
→ Full Screen Section

mt-5
→ Top Space

p-4
→ Inner Space

shadow
→ Card / Box Design

rounded
→ Modern UI

text-center
→ Center Text

btn-success
→ Save / Submit Button

btn-danger
→ Delete Button

To create rounded corners.
