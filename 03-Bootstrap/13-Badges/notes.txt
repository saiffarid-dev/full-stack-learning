# Bootstrap Topic 13
# Badges

=========================================
What are Bootstrap Badges?
=========================================

Bootstrap Badges are small labels used to display notifications, counts, status, or short information.

=========================================
Why Use Bootstrap Badges?
=========================================

- Show Notifications
- Display Counts
- Attractive UI
- Responsive Design
- Easy to Use
- Less Custom CSS

=========================================
Important Badge Classes
=========================================

badge
→ Creates a badge.

bg-primary
→ Blue badge.

bg-success
→ Green badge.

bg-danger
→ Red badge.

bg-warning
→ Yellow badge.

bg-info
→ Sky blue badge.

bg-secondary
→ Gray badge.

rounded-pill
→ Creates a pill-shaped badge.

=========================================
Basic Badge
=========================================

<span class="badge bg-primary">
New
</span>

Creates a simple badge.

=========================================
Notification Badge
=========================================

<span class="badge bg-danger rounded-pill">
5
</span>

Displays notification count.

=========================================
Status Badge
=========================================

<span class="badge bg-success">
Active
</span>

Displays status.

=========================================
Pill Badge
=========================================

<span class="badge bg-primary rounded-pill">
12
</span>

Creates a rounded badge.
