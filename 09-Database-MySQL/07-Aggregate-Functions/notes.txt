========================================
SQL - AGGREGATE FUNCTIONS
========================================

Aggregate Functions:
Aggregate functions perform calculations on multiple
rows and return a single result.

Main Aggregate Functions:

1. COUNT()
   Counts rows/values.

2. SUM()
   Calculates the total of numeric values.

3. AVG()
   Calculates the average of numeric values.

4. MIN()
   Returns the smallest value.

5. MAX()
   Returns the largest value.


----------------------------------------
1. COUNT()
----------------------------------------

COUNT(*) counts the total number of rows.

Syntax:
SELECT COUNT(*)
FROM table_name;

Example:
SELECT COUNT(*) AS total_students
FROM students;


----------------------------------------
2. SUM()
----------------------------------------

SUM() calculates the total of a numeric column.

Example:
SELECT SUM(age) AS total_age
FROM students;


----------------------------------------
3. AVG()
----------------------------------------

AVG() calculates the average of a numeric column.

Example:
SELECT AVG(age) AS average_age
FROM students;


----------------------------------------
4. MIN()
----------------------------------------

MIN() returns the smallest value.

Example:
SELECT MIN(age) AS minimum_age
FROM students;


----------------------------------------
5. MAX()
----------------------------------------

MAX() returns the largest value.

Example:
SELECT MAX(age) AS maximum_age
FROM students;


----------------------------------------
ALIAS (AS)
----------------------------------------

AS gives a readable name to a result column.

Example:
SELECT COUNT(*) AS total_students
FROM students;


IMPORTANT:
Aggregate functions are commonly used with
GROUP BY for grouped calculations.

A: COUNT(), SUM(), AVG(), MIN(), MAX().

Q4. What does SUM() do?
A: It calculates the total of numeric values.

A: It calculates the average of numeric values.

Q6. What does MIN() do?
A: It returns the smallest value.

Q7. What does MAX() do?

A: An alias is a temporary readable name given
